Write each commit message in English using [Conventional Commits](https://www.conventionalcommits.org/). One subject per commit. Follow `docs/GIT_WORKFLOW.md`.

```text
<type>(<optional scope>): <description>
```

Allowed types: `feat`, `fix`, `docs`, `style`, `refactor`, `perf`, `test`, `build`, `ci`, `chore`, `revert`.
